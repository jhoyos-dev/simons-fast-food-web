# 🍔 Simon's Fast Food – Sitio web

Sitio web oficial para el restaurante de comidas rápidas **Simon's Fast Food**, desarrollado como proyecto de la materia **Programación Web** en Ingeniería de Sistemas (Unicatólica, Cali).

> 🚧 **Estado:** en planeación. La propuesta fue presentada en clase y el desarrollo inicia próximamente.

## 🎯 Objetivo

Crear un sitio web multipágina y responsivo que le dé presencia digital al restaurante, muestre su menú y facilite el contacto y los pedidos de los clientes a través de WhatsApp, Instagram y Rappi.

## 📄 Páginas planeadas

| Página | Contenido |
|---|---|
| **Inicio** | Presentación del restaurante y accesos rápidos al menú y contacto |
| **Nosotros** | Historia del restaurante e información de domicilios por Rappi |
| **Menú** | Carta de productos con precios |
| **Contacto** | Botón de WhatsApp, enlace a Instagram y horarios de atención |

Todas las páginas comparten un pie de página con el logo, los íconos de redes sociales y los horarios.

## 🛠️ Tecnologías

- **WordPress** como gestor de contenidos
- **Bootstrap 5** para el diseño responsivo
- **MySQL / MariaDB** como base de datos
- **HTML, CSS y PHP**

## 📱 Diseño responsivo

Un solo sitio adaptable a computador, tablet y celular (iOS y Android), sin necesidad de aplicaciones nativas.
